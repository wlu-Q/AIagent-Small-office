# 寻找与安装 Skills

## 寻找

根据用户目标提取领域和关键词，使用网络搜索查找技能。也可通过终端运行 `npx --yes skills find <关键词>`，或浏览 https://skills.sh/ 。

介绍找到的技能名称、用途和实际来源。优先检查原始仓库的 SKILL.md 及资源目录，确认它确实适合用户的目标。用户已经指定来源或明确要求安装时，不必再走一轮推荐确认。

## 安装

所有来源遵循系统提供的自定义 Skills 目录，不采用其他 Agent 的默认目录或项目内安装位置。

- 使用已有工具下载、克隆、解压或复制，将选中的完整技能目录放入系统给出的安装目录。
- PowerShell 中 `$env:OFFICE_SKILLS_DIR` 是当前用户的真实安装目录；文件工具使用系统提供的 custom Skills 虚拟路径。
- 保留 SKILL.md、scripts、references、assets 等所需文件。一个仓库可能含多个技能，只安装用户要求的内容。
- SKILL.md 的 YAML frontmatter 必须包含 name 和 description；正文是技能说明，不把介绍网页保存成技能正文。
- 外部命令若支持指定目标目录，使用办公室目录；不直接照搬全局安装或符号链接命令。不需要额外注册、构建项目或发布成果。
- 根据实际操作结果说明成功或失败。安装成功后提醒用户：请到员工配置中勾选该 Skill 并保存，下次对话生效。

## 创建与卸载

用户希望编写自己的技能时，按同一目录约定创建 SKILL.md 和必要资源。

用户明确要求卸载时，删除该自定义技能的完整目录；先确认目标位于系统给出的安装目录内，不能删除其他技能或项目文件。
